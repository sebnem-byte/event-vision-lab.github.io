A conventional camera integrates light and outputs image frames at a fixed rate. An **event camera**, by contrast, reports changes in brightness independently at each pixel. Its output is an asynchronous stream of timestamped events, rather than a sequence of full images.

## 1. Brightness changes, not brightness values

At image location $(x,y)$, let the light intensity be $I(x,y,t)$. Most ideal event-camera models use *logarithmic brightness*:

$$L(x,y,t)=\log I(x,y,t).$$

The detector compares current log intensity to the pixel's locally stored reference. A sufficiently large positive or negative change triggers an event. A static scene does not necessarily produce events: the camera is sensitive to temporal contrast, not to static intensity alone.

## 3. From light to asynchronous events: electronics, mathematics and biological inspiration

### Physical interpretation of the circuit

The **photodiode** converts incident light into photocurrent. The analog **photoreceptor** produces a roughly logarithmic response. A **change detector** measures temporal contrast relative to a stored reference; ON/OFF **comparators** trigger when that contrast exceeds corresponding thresholds. After event generation, an internal feedback/reset mechanism allows the pixel to detect new contrast changes.

The electronic circuit is **neuromorphic** in the sense that change-triggered sparse messages are inspired by biological vision. The simplified retina pathway is an analogy, not a transistor-level implementation of retinal neurons.

## 4. Event trigger and reference update

An event is represented by a tuple:

$$e_k=(x_k,y_k,t_k,p_k),\qquad p_k\in\{-1,+1\}.$$

For a pixel with stored reference $L_{\mathrm{ref}}$, define

$$\Delta L(x,y,t)=L(x,y,t)-L_{\mathrm{ref}}(x,y).$$

An **ON event** is triggered when $\Delta L\ge C_+$; an **OFF event** when $\Delta L\le -C_-$. In the symmetric ideal model, both threshold magnitudes equal $C$, and the reference advances after the event:

$$L_{\mathrm{ref,new}}=L_{\mathrm{ref,old}}+p_k C.$$

This updated reference explains why one continuously changing intensity waveform can produce multiple ON events (or multiple OFF events). Actual sensors exhibit threshold mismatch, noise and non-zero latency.

## 5. What does high temporal resolution mean?

A 30 FPS conventional camera samples frames approximately every 33.3 milliseconds. An event camera does not wait for a full frame interval; it assigns timestamps to independently generated brightness-change events. Modern sensors can report timestamp precision in the microsecond range, although **timestamp resolution, photoreceptor bandwidth, latency and event throughput are different quantities**.

This helps characterize fast motion, but it does not guarantee that every very short brightness fluctuation will be detected. The quality of event measurements depends on illumination, contrast, sensor biases, noise and readout capacity.

## 6. DVS versus DAVIS: what is actually measured?

A **DVS** pixel outputs temporal contrast events. A **DAVIS** pixel additionally provides an **APS** intensity/frame pathway. In a typical DAVIS architecture, both share the light-sensing photodiode, while the downstream circuits serve different measurement types.

| Sensor pathway | Output | Trigger or readout mechanism |
| --- | --- | --- |
| DVS | ON/OFF event $(x,y,t,p)$ | Local threshold crossing |
| APS | Grayscale image frame | Exposure and frame readout |

## 7. What happens after event generation?

Raw event streams can be projected or accumulated for visualization and computation. An **event image** summarizes pixel activations in an interval, a **voxel grid** partitions the event stream into temporal bins, and a **time surface** records how recently each pixel generated an event. These representations retain different amounts of temporal information.

For motion estimation, feature tracking, VIO and SLAM, the representation should be chosen based on the algorithm's needs rather than assuming that every event must first be converted into a conventional image.

## 8. Important limitations

High temporal precision does not make event sensing universally superior to conventional imaging. A nearly static, low-contrast scene can yield too few useful events. Conversely, very fast global intensity fluctuations can flood the readout. Dark conditions can reduce useful signal and increase noise; real sensors also have finite response times and pixel-to-pixel threshold variation.
