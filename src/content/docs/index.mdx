Welcome to **Event Vision Lab**. Follow the modules in order if you are new to event cameras.

1. [How Event Cameras Work](/event-vision-lab.github.io/fundamentals/how-event-cameras-work/) — physics, contrast threshold and interactive simulator.
2. [Mathematical Model](/event-vision-lab.github.io/fundamentals/mathematical-model/) — event trigger model and assumptions.
3. [Understanding Event Data](/event-vision-lab.github.io/data-processing/event-data/) — MVSEC and `(x,y,t,p)`.
4. [Event Representations](/event-vision-lab.github.io/data-processing/event-representations/) — event frames, voxel grids and time surfaces.
5. [Perception](/event-vision-lab.github.io/perception/overview/) — the next stage.
6. [VIO & SLAM](/event-vision-lab.github.io/vio-slam/roadmap/) — advanced roadmap.

The course uses [Event-Based Vision: A Survey (Gallego et al.)](https://doi.org/10.1109/TPAMI.2020.3008413) as its principal foundation.
